# 05: 任意双版本对比与一键回滚

**What to build:** 用户在历史记录面板中可以任选两个历史版本进行两两 Diff 对比（不仅限于与当前工作区对比），并且可以点击任一历史版本执行“回滚”，安全将工作区恢复至该历史版本内容。

**Blocked by:** 03: 工作区实时 Diff 对比与双视图切换, 04: 版本快照保存与历史时间轴浏览

**Status:** ready-for-agent

- [ ] 历史面板支持选择两个版本并在 Diff Editor 中呈现两者的差异
- [ ] 历史版本详情提供“回滚至此版本（Revert）”按钮，点击后恢复至工作区并触发保存
- [ ] 编写双版本对比切换与版本回滚功能的端到端交互测试
